# VSCO Native Kit

Unified native wrappers for React Native libraries, distributed as a single iOS SPM package and Android AAR. This kit bundles all native dependencies required by React Native modules (react-native-svg, expo-file-system, react-native-safe-area-context, react-native-camera, etc.) into a single package for easy consumption in native apps.

## Structure

### iOS (Swift Package Manager)

- **Package Name**: `VSCONativeKit`
- **Location**: `ios/VSCONativeKit/Package.swift`
- **Modules**:
  - `VSCOSvg` - react-native-svg native wrapper
  - `VSCOSafeAreaContext` - react-native-safe-area-context native wrapper
  - `VSCOCamera` - react-native-camera native wrapper
  - `VSCOExpoFileSystem` - expo-file-system native wrapper
  - `VSCOExpoModulesCore` - expo-modules-core native wrapper

### Android (AAR)

- **Package Name**: `com.vsco.nativekit`
- **Group ID**: `com.vsco`
- **Artifact ID**: `vsco-native-kit`
- **Version**: `1.0.0`
- **Location**: `android/build.gradle`
- **Modules**:
  - `com.vsco.nativekit.svg` - react-native-svg native wrapper
  - `com.vsco.nativekit.safeAreaContext` - react-native-safe-area-context native wrapper
  - `com.vsco.nativekit.camera` - react-native-camera native wrapper
  - `com.vsco.nativekit.fileSystem` - expo-file-system native wrapper
  - `com.vsco.nativekit.expoModulesCore` - expo-modules-core native wrapper

## Generation

The native kit is automatically generated by scanning all modules published to Verdaccio and detecting their native dependencies. The generation scripts bundle all detected native dependencies into a unified package.

### Prerequisites

1. **Verdaccio must be running**:

   ```bash
   npm run verdaccio:start
   ```

2. **All modules must be published to Verdaccio**:
   ```bash
   npm run publish:verdaccio
   ```

### Generating Native Kits

```bash
# Generate Android native kit AAR
npm run native-kit:android

# Generate iOS native kit SPM
npm run native-kit:ios
```

The scripts will:

1. Detect all modules in Verdaccio (`@app/module-products`, `@app/module-cart`, `@app/module-pdp`)
2. Scan each module for native dependencies (react-native-_, expo-_)
3. Bundle all native code into a unified package
4. Generate the appropriate package format (AAR for Android, SPM for iOS)
5. Publish to Maven Local (Android) or generate SPM package (iOS)

## Usage

### iOS

Add the SPM package to your Xcode project:

1. In Xcode: `File > Add Package Dependencies...`
2. Navigate to: `vsco-native-kit/ios/VSCONativeKit`
3. Select the package and add it to your target

```swift
// Import unified package
import VSCONativeKit

// Or import individual modules
import VSCOSvg
import VSCOSafeAreaContext
import VSCOCamera
import VSCOExpoFileSystem
import VSCOExpoModulesCore
```

### Android

Add the AAR to your `app/build.gradle`:

```gradle
repositories {
    mavenLocal()  // Required to resolve the published AAR
    // ... other repositories
}

dependencies {
    // Native Kit (includes all native dependencies)
    implementation 'com.vsco:vsco-native-kit:1.0.0'

    // React Native Runtime (required)
    implementation 'com.vscorp:vsco-rn-host-sdk:1.0.0'
}
```

In your `MainApplication.kt`:

```kotlin
import com.vsco.nativekit.VSCONativeKitPackage
import expo.modules.ExpoModulesPackageList
import expo.modules.adapters.react.ModuleRegistryAdapter

class MainApplication : Application(), ReactApplication {
    override fun getPackages(): List<ReactPackage> {
        val packages = PackageList(this).packages

        // Register Expo Modules bridge (if using expo-* modules)
        packages.add(ModuleRegistryAdapter(ExpoModulesPackageList.getPackageList()))

        // Register Native Kit
        packages.add(VSCONativeKitPackage())

        return packages
    }
}
```

## Building

### iOS SPM

The package can be consumed directly via SPM in Xcode. No manual build step is required - Xcode will build it automatically when you add it as a dependency.

To validate the package structure:

```bash
cd ios/VSCONativeKit
swift package describe
```

### Android AAR

The AAR is automatically built and published to Maven Local during generation. To manually build:

```bash
cd android
./gradlew assembleRelease
# AAR will be in android/build/outputs/aar/vsco-native-kit-release.aar
```

To publish to Maven Local:

```bash
cd android
./gradlew publishReleasePublicationToMavenLocal
```

## Integration

### With Module Frameworks

The native kit is automatically included as a dependency when generating module frameworks (AARs and SPMs). Module frameworks reference the native kit to provide all required native dependencies.

### Expo Modules Support

When Expo modules (expo-\*) are detected in modules, the native kit includes:

- `expo-modules-core` - Core Expo modules runtime
- `ExpoModulesPackageList` - Auto-generated list of Expo modules
- `kotlin-reflect` - Required for Expo module argument casting (Android)

The native kit generation script automatically:

1. Detects Expo dependencies in modules
2. Includes `expo-modules-core` in the bundle
3. Generates `ExpoModulesPackageList.kt` (Android) with all detected Expo modules
4. Registers Expo modules in the consuming app's `ReactInstanceManager`

## Distribution

### Android

The AAR is published to Maven Local at:

```
~/.m2/repository/com/vsco/vsco-native-kit/1.0.0/
```

To publish to a central repository (e.g., Artifactory), use the publish script:

```bash
./scripts/publish-aar.sh AAR=vsco-native-kit LOCATION=central VERSION=1.0.0
```

### iOS

The SPM package is located at:

```
vsco-native-kit/ios/VSCONativeKit/
```

It can be:

- Added directly to Xcode projects as a local package
- Published to a Git repository for remote access
- Distributed as a binary package (future enhancement)

## Notes

- The native kit is **automatically generated** - do not manually edit the generated files
- All native dependencies are **bundled and renamed** to avoid conflicts (e.g., `com.horcrux.svg` → `com.vsco.nativekit.svg`)
- The kit includes **Expo modules support** when `expo-*` dependencies are detected
- Both Android and iOS kits are **self-contained** and include all transitive native dependencies
